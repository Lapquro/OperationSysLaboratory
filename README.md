# Лабораторная работа: Межпроцессное взаимодействие (IPC)

Репозиторий содержит исходный код лабораторной работы по курсу «Операционные системы». Проект демонстрирует организацию клиент-серверного взаимодействия между родственными процессами с использованием неименованных каналов (`pipe`), подмены стандартных потоков ввода-вывода (`dup2`) и замещения образа процесса (`execve`) в POSIX-совместимых системах.

## Вариант 5: Описание задания

Программа принимает от пользователя команды вида: `число<endline>`.
Введенные данные передаются от родительского процесса к дочернему. Дочерний процесс осуществляет проверку каждого числа на простоту:
*   **Составные числа:** записываются дочерним процессом в целевой текстовый файл.
*   **Простые числа, отрицательные числа, а также `0` и `1`:** выступают в роли сигналов завершения. При их получении дочерний процесс отправляет родителю ответный сигнал, после чего оба процесса штатно завершают работу.

Целевой файл создается автоматически в рабочей директории при его отсутствии. Завершение ввода данных обрабатывается как при вводе пустой строки (Enter), так и при передаче сигнала конца файла (EOF / `Ctrl+D`).

## Архитектура процессов

Программный комплекс состоит из двух исполняемых файлов:

1.  **`parent.c` (Родительский процесс):**
    *   Считывает имя целевого файла из стандартного ввода.
    *   Инициализирует два неименованных канала: для передачи данных (`pipe1`) и для приема сигнала завершения (`pipe2`).
    *   Порождает дочерний процесс системным вызовом `fork()`.
    *   Перенаправляет файловые дескрипторы `stdin` и `stdout` дочернего процесса на соответствующие концы каналов.
    *   Замещает образ дочернего процесса вызовом `execve()`.
    *   Осуществляет трансляцию пользовательского ввода в канал данных с одновременным асинхронным мониторингом статуса дочернего процесса (`waitpid` с флагом `WNOHANG`).
    *   Игнорирует системный сигнал `SIGPIPE` для предотвращения аварийного завершения при записи в закрытый канал.

2.  **`child.c` (Дочерний процесс):**
    *   Считывает поток байт из перенаправленного `stdin`.
    *   Осуществляет парсинг и математическую проверку поступающих чисел.
    *   Управляет файловым вводом-выводом, записывая составные числа напрямую в файл через системные вызовы `open` и `write`.
    *   При наступлении терминального условия передает символ `'X'` в перенаправленный `stdout` и завершается.

## Сборка программы

Для сборки проекта требуется утилита **CMake** (минимальная версия 4.2) и компилятор с поддержкой стандарта **C23** - согласно лично моему проекту, формально требования ниже.

```bash
mkdir cmake-build-debug
cd cmake-build-debug
cmake ..
make
```

## Запуск

Запуск осуществляется вызовом бинарного файла родительского процесса из директории сборки. Бинарный файл дочернего процесса (`child`) должен находиться в той же директории. Процесс `child` запускать вручную не требуется.

```bash
./parent
```

## Тесты для проверки программы

### Тест 1: Завершение по простому числу

**Ввод пользователя:**
```text
output.txt
4
6
8
10
7
```

*   **Ожидаемый вывод в консоль:** `From parent: terminate signal 'X' reached. Exiting!`
*   **Ожидаемое содержимое файла `output.txt`:** 
```text
4
6
8
10
```

### Тест 2: Завершение работы по концу потока ввода (EOF)

**Ввод пользователя:**
```text
data.txt
14
15
```
*(После ввода 15 нажать `Ctrl+D`)*

*   **Ожидаемый вывод в консоль:** `Nothing to read. Bye!`
*   **Ожидаемое содержимое файла `data.txt`:**
```text
14
15
```

### Тест 3: Завершение по отрицательному числу или нулю

**Ввод пользователя:**
```text
log.txt
12
-5
```

*   **Ожидаемый вывод в консоль:** `From parent: terminate signal 'X' reached. Exiting!`
*   **Ожидаемое содержимое файла `log.txt`:**
```text
12
```
